# VidLoCraft

**VidLoCraft — Video Local Craft.** Інструменти для відео й звуку, які працюють повністю у браузері, на вашому пристрої: файли нікуди не завантажуються, а сторінка працює навіть без інтернету.

## Що вміє

- **Цикли** — повторити відео потрібну кількість разів (або 1× як простий конвертер); без перекодування, з перекодуванням у фоні або компактним файлом.
- **Конвертер** — формати MP4 / WebM / MKV / MOV і звук MP3 / M4A / WAV / OGG; якість, бітрейт, «стиснути до N МБ», роздільність, частота кадрів; обрізка й поділ; поворот, кадрування, формат 9:16 з розмитим фоном; колір, логотип, текст, субтитри; швидкість і реверс; заміна чи змішування звуку, гучність, плавні переходи; видалення метаданих; пакетна обробка й пресети.
- **Кадри й GIF** — кадр, кадри кожні N секунд (ZIP), аркуш мініатюр, GIF, анімований WebP.
- **Склеювання** кількох відео в одне.
- **Створити відео** з картинки й звуку або слайд-шоу з картинок.

## Як користуватися

Відкрийте `index.html` у Chrome або Edge — це один файл, усе потрібне вже всередині.

Щоб встановити як застосунок (PWA) і відкривати відео через «Відкрити за допомогою», сторінку треба відкрити з сайту по https (наприклад, GitHub Pages), разом із файлами `manifest.webmanifest`, `sw.js` та іконками.

## Для розробки

Бібліотеки й стилі вбудовані в `index.html`. Після змін їх перезбирають (потрібні Node.js та інтернет):

- `node tools/build-css.mjs` — стилі Tailwind;
- `node tools/build-libs.mjs` — Mediabunny (MPL-2.0), MP3-кодувальник LAME, gifenc, mp4box.js.
